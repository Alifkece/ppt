Chapter 02 — Introduction

Rasa Nusantara, Dalam Setiap Seduhan

Kopi Nusantara adalah website e-commerce biji kopi pilihan dari berbagai daerah Indonesia. Pengunjung dapat menjelajahi asal-usul kopi, memilih dari 16 varietas, memasukkannya ke keranjang, lalu menyelesaikan pesanan lewat WhatsApp atau QRIS. Dibangun tanpa framework: HTML, CSS, dan JavaScript murni di sisi klien, dengan Firebase untuk akun pengguna dan fungsi serverless kecil untuk verifikasi OTP lewat Gmail.

Chapter — Security Architecture

Authentication, Email Verification & Data Protection

Konfigurasi OTP — nilai aktual dari api/lib/session.js

Panjang kode OTP6 digit
Masa berlaku kode5 menit
Jeda kirim ulang (resend cooldown)60 detik
Maksimal percobaan5 kali
Masa berlaku status terverifikasi12 jam
Cookie sesikn_otp & kn_verified
Penandatanganan cookieJWT HS256
Alamat yang didukung@gmail.com saja

Endpoint serverless (Vercel Functions)

POST/api/send-otp — verifikasi ID token, buat kode, kirim via Gmail SMTP
POST/api/verify-otp — cocokkan kode dengan cookie kn_otp, lalu set kn_verified
GET/api/check-verified — cek status (read-only), header Authorization: Bearer <idToken>
Rahasia hanya di server: GMAIL_USER, GMAIL_APP_PASSWORD, SESSION_SECRET (min. 16 karakter), FIREBASE_PROJECT_ID — diset via environment variables, tidak pernah dikirim ke klien.

Arsitektur verifikasi (dari kode api/)

Pembatasan domain Gmail diperiksa dari Firebase ID token yang sudah diverifikasi server (bukan teks input pengguna), dengan regex ^[a-zA-Z0-9._%+-]+@gmail\.com$. Ini adalah kebijakan pengendalian pendaftaran: membatasi alamat email yang dapat digunakan, mengurangi potensi pendaftaran spam, dan menjaga kualitas data akun. Namun ini bukan jaminan keamanan mutlak dan tidak otomatis mencegah database penuh — pengelolaan data tetap membutuhkan validasi, kebijakan data, dan pengelolaan akun yang tepat.
OTP adalah lapisan verifikasi tambahan setelah Firebase Authentication berhasil. Verifikasi ID token dilakukan tanpa Admin SDK: signature RS256 dicek terhadap JWKS Google (securetoken@system.gserviceaccount.com), plus validasi iss, aud, exp, dan auth_time.
Chapter — Database & Backend

Teknologi yang Benar-Benar Dipakai

Frontend

HTML5 · CSS3 · Vanilla JavaScript (script.js, 72 KB) · Bootstrap 5.3.3 · Google Fonts (Cormorant Garamond & DM Sans)

Animasi

GSAP 3.12.5 + ScrollTrigger (motion.js) — dengan fallback CSS/IntersectionObserver dan dukungan prefers-reduced-motion

Authentication

Firebase Authentication (SDK 10.13.2, modular ES) — Email/Password + Google Sign-In · persistensi browserLocalPersistence · layar masuk berbasis video (terpisah mobile/desktop)

Database

Cloud Firestore — dokumen profil pengguna pada koleksi users (sesuai dokumentasi proyek). Keranjang disimpan di localStorage per akun; pencatatan pesanan melalui modul js/orders.js dengan status awal “menunggu” — bukan klaim transaksi realtime di Firestore.

OTP API

Node.js runtime · Vercel Functions · tanpa dependensi npm (crypto bawaan Node) · JWT HS256 untuk cookie sesi

Email Delivery

Gmail SMTP via koneksi TLS langsung (smtp.gmail.com:465) — AUTH LOGIN dengan Gmail App Password, tanpa nodemailer

Deployment

GitHub + GitHub Actions (workflow pages.yml ke GitHub Pages) · Vercel untuk fungsi serverless · domain kopi-nusantara.biz.id · vercel.json dengan HSTS & CSP report-only · SEO: robots.txt, sitemap.xml, JSON-LD Store, Search Console
